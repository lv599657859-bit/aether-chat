## 二、流水线

一条消息进来，不再直接进生成函数，而是过一串环节：

```
限流(10) → 兴趣度(20) → 心流(30) → 表达学习(35) → 沉浸守门(40)
```

每一环返回三种结果之一：

- `.proceed` —— 继续
- `.stop(reason)` —— 到此为止，这次不回
- `.annotate(text)` —— 继续，但往 system prompt 里加一句

**加一条规则 = 加一个 stage。** 比如「半夜不回工作消息」，
写一个 `NightGuardStage` 注册进去就行，生成逻辑一行不用碰。

### 兴趣度在做什么

「收到消息就回复」是机器人行为。真人会判断这话跟自己有没有关系、
现在想不想聊。打分依据：

- 被叫名字 +0.5
- 聊到她在意的事 +0.35（按命中数）
- 正好是她憋着想说的 +0.3
- 对方在情绪里 +0.15
- 关系亲密度 × 0.25
- 一句话的「在吗」 −0.1

私聊阈值 0.12，群聊 0.45。**低于阈值就真的不回** —— 这是刻意的，
因为「从不冷场」这件事本身就是最不像人的地方。

### 心流在做什么

她有一个持续的内在状态：此刻在做什么、憋着想问什么、攒着想说什么。
没聊天的时候也在过时间。下次开口时是从一个**正在进行中的状态**里说话，
而不是从空白开始。

提示词里明确写了：不要写「我在等你的消息」。她有自己的生活。

### 表达学习在做什么

她会吸收你的说法。离线抓称呼模式（老X、X哥、X宝）和反复出现的短句；
有模型时让它自己从最近二十条消息里挑「值得学去的表达」。
出现三次以上才算学进去，注入时会注明：

> 用起来要自然 —— 偶尔带一句就够，每句都用会变成学舌。

## 三、内置代理（方案 A）

```
想 → 挑工具 → 执行 → 看结果 → 再想 → …… → 收尾
```

最多六步。工具调用沿用演出系统那套 ⟦⟧ 标记：

```
⟦think:先查一下她的设定⟧
⟦tool:web_search⟧{"query":"钟离 原神 设定"}
```

### 工具清单

内核（跨平台）：
`web_search` `fetch_page` `research_character` `create_character`
`list_characters` `recall_memory` `remember`

外壳（依赖平台框架，启动时注册）：
`design_voice`

**联网那个不需要任何密钥**（DuckDuckGo 打底、维基兜底）。
一个离了 API Key 就连不上网的代理，不配叫「自己去查」。

## 四、远程桥接（方案 C）

### 为什么是这个形态

把真正的 DSH（Node/TS）塞进 iOS 需要 NodeMobile，体积 +100 MB，
App Store 基本不可能过审，而且 DSH 的工具全是桌面语义（读写文件、跑命令），
在沙盒里全废。所以反过来：**让手机连电脑**。

### 它是怎么工作的

```
手机上的代理
   └─ dsh_ask 工具
        └─ HTTP POST http://<电脑IP>:8787/ask
             └─ 电脑上 spawn  dsh --profile headless "<任务>"
                  └─ 完整的 DSH：联网、文件、命令、子代理、技能
                       └─ 输出原样回给手机
```

实测：手机问「AetherCore 里有多少个 Swift 文件」，
电脑开一个 DSH 会话去数，**7.5 秒**返回结果。

**app 本身没有变大一点。** 桥接暴露什么，手机就多出什么工具 ——
这正是工具注册表存在的理由。

### 两道独立的闸

| 闸 | 位置 | 默认 |
|---|---|---|
| `--allow` | 电脑端启动参数 | `ask,read,ls` |
| 能力开关 | 手机设置页 | 与电脑端一致的子集 |

**两道都开才通。** 电脑端是「我允许你碰」，手机端是「我愿意用它」。

危险能力（`exec` 跑命令、`write` 写文件）两边都要显式打开，
手机端还会弹二次确认：

> 危险：任何拿到你手机的人都能用它操作你的电脑

### 还有一层：路径沙箱

`read`/`write`/`ls` 只能碰 `--roots` 指定的目录，默认是启动时的工作目录
加上 `DSH_HOME`。越界直接拒绝：

```json
{"ok":false,"error":"这个路径不在允许范围内"}
```

### 启动

```bash
cd AetherChat
node Tools/dsh-bridge.mjs                    # 默认，只开 ask/read/ls
node Tools/dsh-bridge.mjs --allow ask,read,ls,exec,write   # 全开，想清楚再用
node Tools/dsh-bridge.mjs --port 9000 --roots D:\\work     # 换端口和目录
```

启动后会打印主机地址、端口、令牌。令牌持久化在 `~/.aether-dsh-bridge.json`，
不用每次重填。手机和电脑要在同一个 Wi-Fi 下。

### 它不是什么

- 不是加密的。局域网内明文 HTTP。**不要在公共 Wi-Fi 上开 `exec`。**
- 不是自动发现的。地址要手填。
- 没有远程唤醒。电脑关机或睡眠就连不上。

## 五、接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/status` | 握手，返回名称/版本/已开放能力/可读写目录 |
| POST | `/ask` | `{prompt, timeout?}` → 交给电脑上的 DSH |
| POST | `/exec` | `{command, cwd?, timeout?}` |
| POST | `/read` | `{path}` |
| POST | `/write` | `{path, content}` |
| POST | `/ls` | `{path?}` |

全部需要 `Authorization: Bearer <令牌>`。无令牌返回 401，
能力未开放返回 403，越界路径返回 500 带原因。
